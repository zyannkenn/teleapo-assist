# テレアポ架電サポート

Androidスマホで営業架電を回すための軽量Webアプリです。CSVの顧客リストを取り込み、電話アイコンから標準電話アプリを開き、通話結果やメモを記録できます。

## 主な機能

- CSVファイル取り込み
- CSV貼り付け取り込み
- 会社名・担当者名検索
- リスト行の電話アイコンから発信画面を開く
- 架電結果とメモの記録
- CSV出力、コピー、共有
- 端末内ブラウザ保存

## CSV形式

1行目に見出しがある場合は、以下のような列名を自動判定します。

```csv
名前,会社,電話番号
山田太郎,山田工務店,090-1234-5678
佐藤花子,佐藤商事,03-1234-5678
```

GitHub Pagesでは `index.html` からアプリ画面へ移動します。
